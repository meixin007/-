# E2：反向空间桶、可见查询和绘制计划

本批只增加E2代码、测试和独立构建；E1加载器、包协议、V1素材、旧地图与已封存收据不变。E1仍同步加载，E3资源调度/预算/卸载不在本批声明中。

Bucket以512m、负坐标floor、半开矩形派生，引用完整paint范围内的对象ID；不复制可独立修改的对象。唯一对象记录保留原ID、owner与payload分片依赖。查询从视口桶合并候选后做精确paint剔除，不遍历全量对象。

缓存身份包含world/build、有效制作修订、资产范围版本和索引参数。源快照只在修订变化时读取；变更计算后仅重建受影响对象的桶。素材变大时重算其所有使用者的paint范围与桶，保留接地点和ground/protection字段。

只移动相机不重建源快照、完整索引或全量绘制计划。相同候选/显示内容重用稳定排序的可见计划；排序键为render_plane、ground_depth、stable_id。视口变换逐帧更新。实际draw调用前记录提交，重复表示拒绝；只有显式登记的过渡配对可共享实体身份。

测试包含owner在视口外但树冠可见、四块巨树、重复ID与key不一致、负坐标边界、移动/删除/分片变化、换大素材后旧桶失效、仅相机移动、同可见量下1千/1万/10万离屏元数据，以及原生像素参考和实际提交审计。工程元数据规模不等于城市容量或游戏帧时达标。

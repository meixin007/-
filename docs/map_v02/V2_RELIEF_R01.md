# V2 地形结构 R1 审阅候选

针对作者指出坡面、山脊、沟谷表达弱，以及应依据原等高线组织地形的反馈。本次保留原V2院落、墙段、原位建设/损毁/修复与原主机，新增独立`relief_r01`表现组件和数值地形构建，不修改旧V1/V2/E3源码、PNG、发布、地图、地块或高度数据。

## 数据与方法

- 使用原`elevation_f32.bin`的600×400、40m现代DSM；原`review/relief_contours.json`的source_numeric_sha256须与该文件相同。不是从等高线截图猜高度，不改数值源或把美术像素分辨率当测绘精度。
- 在整个数值源上做1.0/3.5格的两档Gaussian分析，计算坡度、坡向法线与统一光向的明暗、局部与广域高度差TPI、横坡曲率。凸凹是候选地势结构，不自动命名山脊/河流，不由高度阈值分类土地用途。
- 所有分页共用固定色阶、世界坐标采样和稳定噪声；不逐页拉对比度。沿源350/420/520m等高线，仅对坡度14—60度且abs(TPI)>=1.5m的短段绘少量浅结构线，顺坡短笔触跟随高度梯度；只作为表现笔触，不是新增地理feature或水系。
- 不移动地面像素的世界位置、不抬高楼/树、不重投影；建筑、原八地块、墙/路接点和通行权威保持。新表现去掉旧小样规则岸边排线及非地形驱动坡脚示意，用新地势和原水域遮罩组织岸坡。
- 细页范围仍为[-1024,-1024,2048,1536]，1024px core/512m，gutter32px；当前仅线性基础层采样，显式无mip。本次不宣称深mip或E3混合LOD验收。另生成一张24×16km原数值源的低分辨率地势参照，不新增历史节点或测绘资料。
- 水域仍来自原modern_water，细页core与旧V1水图逐像素相同。所有新PNG均由数值配方生成，不新增AI绘制资产、不修改原三张V2小样。

## 三种视图

同一相机F1完整组合、F2地形独显、F3原等高线校核；F4切区域地势机位，O切新旧地形。原1—4关河/院落/墙楼/岸坡机位保留，拖动和滚轮可连续观察。新入口先展示区域地势，再回近景比较。完整原等高线只在校核层出现，正式画面不叠满等高线。

V2仍用原FinalController+GameState/Context与绑定SettlementState。原建设、损毁、修复和经济服务未改。只创建新审阅工作副本，E3正式流式调度与本表现入口的合流仍留C1；同屏新旧资源用于A/B审阅，不把这个双版本检查入口当作生产预算验收。整幅GPU参考仅在验证时载入，交互默认不持有参考纹理。

## 验证范围

解析平面、坡向、脊/谷凸凹符号、非法数值、边界采样用独立解析场测试。12页独立重新求值与整幅场比较，RGBA/RGB基础像素须一致；细页水core须保持旧值。原生1920×1080在4档缩放/3处交界比较分页和整幅参考；预先冻结GPU最大单通道差1（线性采样坐标精度），另注入40m错页要求被识别。记录真实差异像素，不把“允许1色阶”写成完全相同。

同时验证三视图与相机序列只读、原位建设/损毁/修复后像素恢复、合同/钱/木料及建筑变换不变。全部旧保护SHA和封存检查独立执行。技术通过、视觉判断、现代地理来源和历史复原分别裁定；视觉始终pending，不能用原生检查数自动接受坡面质量。

# Q1 压力、保护和发布验证

Q1 使用新的构建、报告及独立测试存档目录；接受的 C1 构建为 `tongguan_v02_c1_20261016_04`，作者收据为 `reports/map_v02/C1_A01_ACCEPTED_20261016.json`。原 C1 收据、旧地图、既有素材、原默认入口和旧发行不覆盖。

## 冻结的测量约定

正式参数见 `schemas/map_v02/q1_profiles.json`。正常视觉是原 C1 地形、院落和损毁修复，运行3次60秒及一次300秒，每次10秒预热。所有原始帧均保存；稳态与预热分开汇总，p95≤16.7ms、p99≤25ms，33／50／100ms长帧逐项保留。不把校验采样链路的10秒预演计入正式结果。

单调主循环间隔包含CPU更新、绘制和驱动等待影响，不冒称独立GPU执行耗时。另记视野更新、挂接、绘制计划及资源数量，保留记录器flush事件。截图GPU读回只发生在测量前后。

Windows按目标PID记录PrivateUsage和WDDM GPUProcessMemory DedicatedUsage／SharedUsage／TotalCommitted。Godot纹理／缓冲统计、调度resident＋inflight估算单列；缺失的GPU采样为null，不按0算通过。记录实际客户端尺寸、窗口DPI、Viewport、GPU／驱动、CPU、RAM及完整启动命令。首次进程与后续进程区分，但不宣称已清空OS磁盘缓存。

## 独立工程夹具

- E-stream使用同一个C1 MapService／E3后端，256张不同内容细页，4／8MiB软硬预算，20轮不相邻区域往返。实际访问唯一纹理字节必须超过软预算3倍，逐页保存request／attach／last_reference_drop／released_observed／reload事件，每轮同视野比较资源窗口。
- E-small保留16细页＋父页、实际缺页、四桶巨树。错误哈希、延迟、A-B-A、世界／包epoch、共享图集、父页未就绪和预算缩小分别验证，错误不得伪装成功。
- E-query以1千、1万、10万记录保持同一可见集合，对照全量参考；保存查询耗时、桶、候选、可见、提交和排序计数。
- E-sites为32个工程地点代理及4个现有美术骨架；E-labels为2000个工程地名，屏幕上限64，检查选中优先与避让。这些不是新增历史城市、疆界或美术生产。
- A/B使用未修改的v0.1 review画布和原图，同一轨迹比较原常驻缓存／全量树计划与E2查询／E3资源的兼容适配。它是旧内容过渡链的控制实验；新画风C1实测单列，不据此混算C1提速比例。

## 保护、发布与回退

原REV-01／02／03、建设、通道、Save22、布局固定、发布和50轮重生成仍需通过；原生制作测试另核对受保护画面像素。旧用例在源代码相同、独立user目录的副本运行。原生制作与运行导入需要把实际生成的测试发布明确传入隔离运行目录，不借用历史测试文件。

局部构建用工程数值地面修改证明细页、滤波邻域及父页依赖闭合，未影响页复用；动态对象移动仅更新旧／新paint成员关系，不烘入地面。

Windows发布验证使用全新版本目录与文件哈希，实际测试不完整解包、错哈希、替换前中断、ENOSPC错误边界、画风迁移拒绝、原子指向切换与回退。ENOSPC是写入边界注入，不宣称填满真实磁盘。真实旧EXE及新EXE均需启动验证。新包只能作为本地版本化发行交付，不改原主工程活动指向。

最终报告按正确性、视觉、性能和历史来源分别裁定；任何失败和未执行项保留。C1作者认可不替代Q1性能结论；现代DSM与水域、东亚粗示意不因压力测试通过而变成唐代精确历史复原。

# R4 工程占位范围与正式资产缺口

当前组合画面为用户验收候选。R3接受记录没有被解释为新组合、全部正式美术或历史复原已接受。

|内容|本轮可审阅的工程用途|尚缺的正式制作|
|---|---|---|
|用户选择的关楼PNG|同一像素接地点、同一site_id；固定方向、透明边缘、缩放与图层对照|真实形制和尺寸考证；若正式扩展，需相配的模块接头及损毁变体|

门楼与树林PNG逐字节沿用旧交付。没有编辑原图、批量生成新位图、旋转或镜像门楼。打包启用原图mipmap；边界透明度、尺寸、哈希和包围盒见 `asset_audit.json`。透明边缘检查不等于全部低倍率采样和光向已经得到美术认可。

R4实际采用米制地理平面和固定方向符号。关楼是斜俯视图像，其地上墙体与院落仍为工程示意，两者的统一透视、光向与线粗尚未达到正式资产完成定义。院落只有功能占位信息，不能用增加代码屋顶数量代替正式美术。

四组固定镜头提供R3绘制器/当前R4状态的同镜头对照，建设完成、损毁、修复和隐藏建筑各有截图。已人工核看区域、背景、近景和状态图：无黑块，主干接线与关楼前后层序可辨；DSM近景偏平滑，等高线仍有格网节奏，树林保留稳定采样感，短续墙转折为占位。**ART-01/02当前留给用户审阅，不因48项原生检查通过而标为美术验收通过。**

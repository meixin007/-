# R4 历史选择与未核项

核查语境按用户选择固定为 **756年**。本阶段交付明确的工程选择和证据边界，历史精确性仍为 pending。

《潼关县志》大事记第12页（PDF第54页）记述691迁近黄河南岸；军事设施第539页（PDF第555页）区分隋、唐与后世关城。它支持关址阶段选择，不能定位当前门楼、墙线或地块。地方志是后世编纂材料，不能当作唐代测绘。[陕西省地方志平台原PDF](https://dfz.shaanxi.gov.cn/zslm/fzzlk/xbsxsxz/xbsxz/wns_16202/201405/P020240923621802600949.pdf)

此次实际下载并看了两页渲染图，而非仅采用搜索摘要。下载SHA256为 `091a175d21246e6efcd975713047917495fbcc1730b8c29447852ab5e62a0cd0`。PDF文字映射存在乱码，历史判断以原页视觉核读为准；Poppler的缺字体提示另存，所用两页正文可读。大事记将755年起兵与后续失关压缩在一条记录中，不据此给756战事重新定年。

《资治通鉴》卷218将出关后灵宝西原之战与败退失关相连叙述。这里据以区分战场和关门，不把险道、山河或三堑叙述擅自落成这张局部图的坐标。[卷218原文转录，756年五月至六月段](https://zh.wikisource.org/wiki/資治通鑑/卷218)

现代地理仍是原P3数据：40米格网的DSM与OSM水系。DSM包含现代地表物体，不能证明唐代地基或岸线；水系没有组装全部复合关系，查询边缘也不完整。[Copernicus产品说明](https://dataspace.copernicus.eu/explore-data/data-collections/copernicus-contributing-missions/collections-description/COP-DEM)、[OSM署名与许可](https://www.openstreetmap.org/copyright)

候选原点110.2964°E、34.6028°N、1500米审图圈、24×16公里采样范围均保留原值。圈不是统计置信区间。正式主工程粗点110.23°E、34.55°N与候选约差8448米，本轮仍未移动主工程节点。

完整候选通道与现代水线的4处交点全部标出；它们不是已考证的桥涵，未增加逻辑边。原受控移动仍限于中央600米与明确标为合成的险径。后方8地块通过的是现代粗数据与既有设计约束的完整占地检查。

仍未核定：756精确门址、唐城墙线及尺寸、黄河/渭河当年河槽和高程、禁沟对应、跨沟设施、渡口、40米以下地基、后世改造影响。关门、院落、树林、短续墙均不可作为上述缺口的历史证据。结构化逐条来源及状态见运行源码 `review/history.json`。

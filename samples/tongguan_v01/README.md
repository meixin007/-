# 潼关v0.1样板

2026-10-15公开导出。原生Windows构建 tongguan_v01_final_20261015_03，Godot4.6.1，Compatibility，1920×1080。R5最终用户认可、精确历史与正式美术维持原型边界。

## 操作

- 按1—4召回四档镜头，滚轮连续缩放、拖动平移、点击潼关或地块。
- 建设页选仓储地块，报价开工、推进三天；施工使用实际资源和共享日期。可切成长、损毁并修复。
- 军队页命令关后行军，闭关候行、重开继续。普通部队不能借轻装合成险径；无桥渡边不能跨主河。
- 保存并暂停、重读存档，保留城市/军队/资源/日期/已采用表现。
- 制作端移动仓库、微调支路、固定/删除树、锁区/排除，改变种子/密度后先预览再提交；可撤销重做、保存重开与发布。
- 制作发布后，运行端制作发布页读取默认发布文件。制作几何冻结不妨碍游戏合法施工。
- 存档导入仅接受同合同R3/R4八地块身份映射，先预览再采用；原文件不写。R1/R2、坏校验、未知布局和完整占地越界均拒绝。

user://沿用 %APPDATA%/tongguan_slice_v01_final；游戏存档 final/session.json，上代.bak；制作工作区 authoring/workspace.json，发布 authoring/publication.json。已有数据请保留，测试仅写tests子目录。fixtures为旧程序生成的合成测试存档，不是玩家存档。
